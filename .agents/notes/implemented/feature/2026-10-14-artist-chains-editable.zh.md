# Agent Note: 画师串跨会话持久可编辑

状态：已实现

[English](2026-10-14-artist-chains-editable.md) | 中文

- 日期：2026-10-14
- 包：`client/ui-novelai-workbench`

## 问题

画师串有三个操作者可见的缺陷：折叠栏只在面板每次挂载后读一次宿主库，会话切换或刷新后列表可能过期；已保存的画师串没有编辑路径（只有插入和删除，一个笔误意味着删除重打）；标签文本渲染成单行省略号，藏住大部分精修内容。

持久层从未坏过——宿主 store 在每次变更时原子写入 harness 主目录的 `novelai-artist-chains.json`，保存的画师串一直在盘上。消失感来自面板侧的读取策略，不是存储。

## 决策

- 折叠栏在**每次展开时**重读宿主库，不再每挂载一次。每次展开切换的一次文件读取很便宜，而画师串库是实例级数据，其他座席或会话随时可能改过它。
- 每行新增**编辑**按钮：把已存的名称与标签串载入表单，提交翻转为「保存」并通过 store 既有的按 id 更新原位改写（保持该串的槽位），「取消」把表单退回新增模式。宿主零改动——更新路径本来就在。
- 行布局改纵向堆叠，标签文本完整换行（`pre-wrap`、任意断行）——精修的画师串是逐字数据，任何截断都不允许。编辑中的行带高亮边框。
- 新增双语 locale 键（`artists.edit/update/cancel/editingHint`）；面板 spec 的本地 zh 桩补了同样的键——桩字典与真字典漂移会以空渲染文案的形态失败，编辑测试首跑正是这样红的。

## 后果

- 任何会话保存的画师串在每个会话的面板展开时都在；页面刷新重读持久文件。
- 编辑保持画师串的身份与槽位；删除行为不变。
- 测试侧的 locale 桩必须同步每个新键——i18n 门只守源文件，不守 spec 本地字典。
