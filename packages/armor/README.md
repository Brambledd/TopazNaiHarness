## Summary

The armor group carries the fork's armor persona family — first-party continuations of the Minglink 无限 generations (MIT). One package forms the group today: `infinite-gen-3` registers the verbatim v0.5.0 armor system-prompt section, the `infinite_gen3_profile` self-description tool, the `armor` verdict projection, and the browser badge above the composer. The group is exempt from a standalone subsystem page: the package README and the armor Agent Note own the prompt contract, while the seams the plugin rides (system prompt, tools, session projection) own their own subsystem pages.
